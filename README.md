# Fest Aquathlon 2026 — Landing Page (Fase 1)

Landing page responsiva criada como protótipo inicial para divulgação e inscrição de evento esportivo.

## Estrutura

- `index.html` — página principal
- `style.css` — layout e responsividade
- `main.js` — menu, formulário demonstrativo e modal de pagamento
- `assets/hero-evento.jpeg` — imagem fornecida para o evento

## Como executar

Opção 1: abra `index.html` diretamente no navegador.

Opção 2 (recomendado): use o Live Server do VS Code.
